Why it exists

Canadians increasingly want to find and buy from domestic merchants, but product origin is hard to verify and no single store lists everything Canadian. Buy Canadian searches the Shopify Global Catalog live on every visit — fresh results, no copied catalog — and surfaces products from Canadian sellers with a best-effort “made in Canada” search filter.

How it works

Buy Canadian is a pass-through discovery site. We do not store product listings, prices, or images. Each page load runs live search_catalog and get_product calls through a small server proxy with Canadian shipping filters. When you find something you like, you complete purchase on the merchant’s own Shopify store.

Agent-ready (WebMCP & UCP)

Buy Canadian is built for humans and in-browser AI assistants working together. The site publishes a UCP agent profile at /.well-known/ucp-agent.json for server-side catalog capabilities, and registers WebMCP tools in supporting browsers so an assistant in the same tab can list categories, search products, fetch details, and navigate the visible UI alongside you.

Registered WebMCP tools:

  • list_categories — ranked category list
  • search_products — live catalog search
  • get_product_details — full product by id
  • open_product_page — navigate to a product in this tab
  • open_category_page — navigate to a category listing

Test in the ChatGPT desktop in-app browser or Chrome 149+ with WebMCP enabled. See the GitHub repository for judge testing instructions.
